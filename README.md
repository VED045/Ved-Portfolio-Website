# Ved's Portfolio Website

An interactive personal portfolio website for **Ved Deshpande**, showcasing selected work across AI, computer vision, full-stack development, and product engineering.

The website uses a cinematic single-page design with interactive elements inspired by modern technology and devices.

## Features

- Interactive laptop terminal in the hero section
- 3D Galaxy S25 Ultra-inspired project viewer
- Interactive front and rear camera elements
- Featured projects across AI, computer vision, and full-stack development
- Professional experience timeline
- Responsive design for desktop and mobile
- Keyboard navigation
- Reduced-motion accessibility support
- Smooth animations and interactive UI elements

## Featured Projects

The portfolio highlights six selected projects, including:

- Daily News Intelligence
- TripMate
- AI and Computer Vision projects
- Full-stack applications
- Agentic AI systems

Each project includes a description, technologies used, and relevant project links.
